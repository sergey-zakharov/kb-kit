- One node = **one observed user fact** (need, pain, behavior). Not a feature
  idea, not our opinion — a fact of the user's life (Mom-Test discipline).
- **Evidence is mandatory**: every insight carries at least one
  `[[source#anchor]]: "verbatim quote" (locator)` citation. No verbatim quote in
  any source → this is NOT an insight: park it in INBOX with a question, or
  file it as a `hypothesis` (explicitly unproven).
- Frontmatter `type: insight`; tag the segment (`tags: <segment-slug>, …`) and
  link the segment node.
- Works for discovery interviews AND production feedback (tickets, reviews,
  support chats) — same discipline, different sources.
- Naming: `<what-was-observed>.md`, kebab, specific ("churns-at-paywall-copy",
  not "payment-problems").

- One node = one **falsifiable** statement. If no observable outcome could
  prove it wrong, it is not a hypothesis — rewrite until it is.
- Mandatory sections: **Statement** (falsifiable), **Check plan** (a check you
  can actually run: experiment, interview script, data pull), **Result**
  (what happened; never deleted, only appended).
- Frontmatter `status: pending | validated | invalidated` — updated when the
  Result lands. Invalidated hypotheses stay in the base: they are knowledge.
- A hypothesis that gains verbatim evidence graduates: file the evidence as an
  `insight` and link it; the hypothesis records the outcome.
